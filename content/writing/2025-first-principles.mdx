# 小さな作品を最後まで届ける

アイデアを思いついたとき、実装したい機能はいつも増えていきます。だからこそ、最初に「何を感じてもらえれば成功か」を一文で決めます。

## つくる順番

1. 触った瞬間の体験を決める
2. 最小の状態を実装する
3. 壊れたときのfallbackを用意する
4. 公開環境で自分の目で確認する

記事サイトも、作品と同じく体験の一部です。文章を読む邪魔をしないことを最初の仕様にしました。

~~~text
write -> commit -> push -> deploy
~~~

## 公開後に見るもの

表示速度、スマートフォンの横幅、リンクのfocus状態。小さな確認を積み重ねると、作品の印象が安定します。
